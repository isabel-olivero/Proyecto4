## Project 4 by Ana Gabriela Argüello and Laura Isabel Olivero

In this Project 4, various elements of Pure Data were used to develop an interactive DJ system. This system allows the generation of different types of sounds and the modification of their characteristics, such as volume and speed.

To achieve this, several objects and controls available in the environment were employed, including buttons, sliders and toggles. Thanks to the combination of these elements, the system provides a experience in which it is possible to experiment with different sound effects.
